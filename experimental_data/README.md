# Experimental data credits

- Grain-boundary data: Elizabeth Heon.
- Quasicrystal data: Darel Pates.
- Gold-in-TiO2 data: Utkarsh Pratiush.

All five files use the pyTEMlib/NSID `.hf5` format. Each contains one `Channel_000`
dataset titled `HAADF`, calibrated spatial axes in nanometres, and the source-selection
and data-credit metadata used by the publication workflow.
